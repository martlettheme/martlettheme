# Contributing

Martlet is under active development. Contributions can propose adjustments to either appearance, but should preserve the recognizable blue, silver, and gold drawn from James P. Howard, II’s personal heraldic identity.

1. Modify `src/palettes.mjs` (not the generated CSS).
2. Run `npm run tokens && npm test && npm run build`.
3. Explain any contrast changes and update the project changelog.
4. For application ports, provide an implementation screenshot, installation instructions, and the application's applicable packaging/licensing requirements.

Please avoid embedding unlicensed brand assets, heraldic artwork, or assets from other color theme projects.
